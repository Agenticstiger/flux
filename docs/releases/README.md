# What's New

| Version | Date | Highlights |
|---|---|---|
| **[0.5.5](/flux/releases/0.5.5)** | 2026-11-25 | The FLUID 0.7.7 preview moves to a newer forge-cli commit: a validity window's open end and version chain, an entity's lifecycle and as-of relationships; Airflow ids past 250 characters and an EMR on EKS label without an image are refused |
