# Tutorial

A tutorial is a lesson. You follow it from the top and it works the first time, so you
come away having done the thing rather than having read about it.

- [First evidence pack in five minutes](./first-evidence-pack.md): create a small
  project, run it, verify it, pack the evidence, and change one number to see what moves.

When you want to do something specific, the [how-to guides](../how-to/README.md) come
next.
